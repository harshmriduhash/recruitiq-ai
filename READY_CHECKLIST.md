# Ready-for-Beta-Users Checklist

Sign here before inviting the first external user.

## Smoke test
- [ ] Fresh signup completes without error
- [ ] Google OAuth completes without error
- [ ] Password reset email received and reset works
- [ ] Onboarding wizard completes end-to-end
- [ ] First job created with realistic JD
- [ ] Resume upload → match score → breakdown all render
- [ ] Team invite email received and accepted
- [ ] Upgrade to Starter tier processes payment
- [ ] Downgrade to Free preserves data (read-only)
- [ ] Account deletion moves data to soft-delete state

## Content
- [ ] Marketing copy free of typos
- [ ] Legal pages accurate
- [ ] Support email monitored
- [ ] Onboarding email drip configured (or explicitly deferred)

## Support
- [ ] Bug report path defined
- [ ] Feedback channel (Discord / email / in-app)
- [ ] On-call rotation (who wakes up if pipeline errors spike)
